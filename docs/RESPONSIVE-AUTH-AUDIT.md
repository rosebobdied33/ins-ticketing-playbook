# 第六轮：双端、深层内容与登录

- 桌面：210px 左目录 + 宽阅读区；首页引导与守则入口并排，章节三列。
- 守则：图解 / 解释双栏，标题和翻页横跨两栏。
- 票型：宽屏五列时间轴、四列权益；流程三列；分级与案例票表双列。
- 手机：390px 纵向阅读，保留固定对称翻页、目录、搜索与退出。
- 第三章：二维票型构成、分级票型模块、优惠对象与限制。
