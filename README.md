# INS TICKETING PLAYBOOK

React + Vite + TypeScript 票务知识手册，发布于 GitHub Pages。

## 在线阅读
https://rosebobdied33.github.io/ins-ticketing-playbook/

## 本地开发与构建
- Node.js 22
- `npm ci`
- `npm run dev`
- `npm run build`

推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 简单访问入口
页面使用前端账号入口，便于团队成员统一输入账号后阅读。GitHub Pages 是静态托管：该入口不属于服务端认证，不能保护源代码或内容不被技术用户查看。
